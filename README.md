# Оно тебе надо

Одностраничный сайт аукциона вещей, в которые никто не верил.
Проектная работа курса «Веб-разработчик» Яндекс Практикума.

## Стек

- HTML5 (семантическая разметка)
- CSS3 (Grid, Flexbox, позиционирование)

## Структура проекта

- `index.html` — разметка страницы
- `styles/` — стили (`global.css` — сброс и общие настройки, `style.css` — стили проекта)
- `fonts/` — шрифты и `fonts.css`
- `images/` — изображения

## Запуск

Открыть `index.html` в браузере.
